# CP26 paper artifacts

This directory keeps the CP26-specific table generators beside their LaTeX
outputs:

- `scripts/` contains the Python programs that read experiment results.
- `tables/` contains the generated LaTeX table fragments.

Run a generator from the repository root, for example:

```bash
python papers/cp26/scripts/final_par2.py
```

Most tables are generated by the script with the matching stem.
`tables/train_time.tex` is currently maintained without a corresponding
generator.
